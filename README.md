## About

**Lyx Editor** is a lightweight photo editor focused on simplicity and ease of use.

Built with **Python** and **Flet**, the project aims to provide essential photo editing tools through a clean and modern interface, without the complexity of professional editing software.

Lyx Editor is **free and open source**, and anyone is welcome to use, modify, and contribute to the project.

---

## Features

- Open and view images
- Basic image editing
- Crop
- Move and navigate images
- Zoom
- Image adjustments
- Undo and redo
- Save edited images
- Modern interface
- Windows executable

More features are being added as development continues.

## Download

A **Windows executable** is available, so you can use Lyx Editor without installing Python or the project's dependencies.

Go to the **[Releases](../../releases)** page and download the latest version.

### Windows

1. Download the latest `.exe` from Releases.
2. Run the application.
3. Open an image and start editing.

---

## Run from Source

If you want to run or modify the source code, you can clone the repository and install the required dependencies.

```bash
git clone https://github.com/YOUR_USERNAME/lyx-editor.git
cd lyx-editor
```

Install the dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python main.py
```
