## About

**Lyx Editor** is a lightweight photo editor designed to make basic image editing simple and accessible.

It provides a clean interface with essential editing tools, image adjustments and a straightforward workflow.

No complicated setup is required. Just download the Windows executable and start editing.

---

## Features

- Open images
- Image preview
- Zoom and navigation
- Crop
- Move tool
- Image adjustments
- Undo and redo
- Save edited images
- Clean and modern interface
- Windows executable

More features will be added in future versions.

---

## Download

### Windows

Download the latest version from the **[Releases](../../releases)** page.

The `.exe` version allows you to run Lyx Editor without installing Python or any additional dependencies.

### Installation

No installation is required.

1. Download `LyxEditor.exe`.
2. Place it wherever you want.
3. Double-click the executable.
4. Start editing your images.
